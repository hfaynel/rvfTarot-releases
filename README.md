# rvfTarot

Le jeu de tarot à la française de rvfGames, gratuit : à 3, 4 ou 5 joueurs,
contre des bots ou en ligne avec vos amis. En français et en anglais.

## Télécharger

**[Dernière version](https://github.com/hfaynel/rvfTarot-releases/releases/latest)**,
puis, dans « Assets » :

- **Windows** : `rvfTarot-<version>-setup.exe`, l'installeur. Il ajoute rvfTarot au
  menu Démarrer ; il se désinstalle depuis Paramètres > Applications. Une
  nouvelle version s'installe par-dessus l'ancienne, vos parties et vos options
  gardées.
- **Android** : `rvfTarot-<version>.apk`, à ouvrir sur le téléphone. La première
  fois, Android demande d'autoriser l'installation d'applications depuis le
  navigateur. Une nouvelle version s'installe par-dessus l'ancienne.
- **Windows, sans installer** : `rvfTarot-<version>-windows.zip`, à décompresser,
  puis lancer `rvfTarot.exe`.

Au premier lancement, Windows peut afficher « Windows a protégé votre
ordinateur » : le jeu n'est pas encore signé. Cliquez sur « Informations
complémentaires », puis « Exécuter quand même ».

Sur ordinateur : Échap pour revenir en arrière, Entrée pour la donne suivante,
F11 pour le plein écran.
